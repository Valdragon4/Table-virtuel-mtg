# Polices auto-hébergées

Deux familles, servies depuis ce dossier et jamais depuis un CDN tiers : le site
est français et une requête vers `fonts.gstatic.com` à chaque visite est un
transfert de données personnelles qui n'apporte rien ici.

| Fichier | Famille | Licence | Origine |
|---|---|---|---|
| `archivo-latin.woff2`, `archivo-latin-ext.woff2` | Archivo (variable, `wdth` 62–125, `wght` 400–900) | SIL Open Font License 1.1 | Omnibus-Type, via le catalogue Google Fonts (v25) |
| `courier-prime-400-latin.woff2`, `courier-prime-400-latin-ext.woff2`, `courier-prime-700-latin.woff2` | Courier Prime | SIL Open Font License 1.1 | Quote-Unquote Apps, via le catalogue Google Fonts (v11) |

Les deux sont sous OFL 1.1 : redistribution et intégration à un projet
autorisées, y compris ici. Elles sont déclarées dans
`src/styles/identity.css` sous les noms `Archivo Site` et `Courier Site`, avec
les mêmes `unicode-range` que les sous-ensembles d'origine.

Ce ne sont pas des assets de Wizards of the Coast, et aucune des deux n'imite la
typographie de la marque.
